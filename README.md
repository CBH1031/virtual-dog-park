# Virtual Dog Park

Virtual Dog Park  A small practice website built with plain HTML, CSS and vanilla JavaScript.
There is no framework, no build step and no backend, so every file can be read
from top to bottom.  The page has three parts:  The Park – click a breed and send it out for a quick walk.  My Virtual Dog – adopt one dog, give it a name, and look after it.  Dog Encyclopedia – short notes on the Beagle, Golden Retriever and Poodle.  Files  week5/
├── index.html   the page itself
├── style.css    all of the styling
├── script.js    all of the interactivity
├── README.md    this file
└── assets/
    ├── beagle.svg
    ├── golden-retriever.svg
    └── poodle.svg    Features  The Park  Three breed cards, each with a "Take to the park" button.  Clicking a button highlights that card and updates the message under "The Park".  "Clear the park" resets the message and removes the highlight.  My Virtual Dog  Choose a breed: Beagle, Golden Retriever or Poodle.  Type a name (up to 20 characters) and press Adopt.  Spaces at the start and end of the name are removed. Spaces inside the name are kept.  An empty or all-space name shows a helpful message instead of adopting.  The dog's name, breed, day, growth stage and happiness are displayed, with a growth bar.  Feed and Play each add 10 happiness. Happiness stops at 100.  Next Day moves the dog forward one day and takes away 5 happiness. It never goes below 0.  Start Over asks for confirmation, then deletes the saved dog and brings back the adoption form.  Only one dog is kept at a time.  Dog Encyclopedia  Each of the three breeds has a name and short notes on size, personality and everyday care.  This section is only for reading. Nothing in it can be broken by the virtual dog feature.  Every button on the page is wired to a handler in script.js. The adoption form
uses <label for="..."> elements that point at the breed box and the name box,
so the labels are connected to their controls and clicking a label focuses the control.  Growth and happiness rules  Growth depends only on the day number:  Day   Growth stage    1   Puppy    2 – 3   Young Dog    4 and beyond   Adult Dog         The growth bar is a picture of the same information. It shows 25% on Day 1, and
reaches 100% on Day 4 and stays there. The stage is always written out in words
as well, so it is never communicated by size or colour alone.  Happiness is a number from 0 to 100. A newly adopted dog starts at 50.  Action   Happiness    Adopt   starts at 50    Feed   +10    Play   +10    Next Day   −5         Happiness is always kept between 0 and 100. Feeding a dog that is already at 100
leaves it at 100, and a dog that has reached 0 stays at 0 no matter how many days
pass.  Where the pet is saved  Pet progress is saved in the visitor's own web browser, using the browser's
built-in localStorage feature, under the key virtualDogParkPetV1.  To be clear about what that means:  There is no account, no login and no server. Nothing is uploaded anywhere.  It is not stored in a GitHub account. GitHub is only where the code files live.  The saved dog lives on that one computer, in that one browser, for that one web address.  Opening the page in a different browser, on a different device, or from a different
address starts fresh with no dog.  Clearing the browser's site data, or using a private / incognito window, also starts fresh.  If a browser blocks storage for local files, the page still works normally — it simply
will not remember the dog after a refresh.  The saved value is a small piece of text that looks like this:  {"name":"Biscuit","breed":"Beagle","day":1,"happiness":50}    You can see it yourself: open the page, press F12, and look under
Application → Local Storage. The dog is saved straight after adoption and again
after every Feed, Play or Next Day action.  Previewing the page  The page uses only local files, so it can be opened in two ways.  Option 1 — VS Code Live Server (recommended)  1.  Install the Live Server extension in VS Code.  2.  Open the week5 folder in VS Code.  3.  Right-click index.html and choose Open with Live Server.  4.  Your browser opens at an address such as http://127.0.0.1:5500/index.html.  Option 2 — any local server  If you have Python installed:  cd week5
python -m http.server 8000    Then open http://127.0.0.1:8000/ in your browser.  Serving the page is the safer habit because it matches how the page will be served
for real. Double-clicking index.html also displays the page correctly.  Manual testing checklist  Work through these steps in the browser by hand.  Getting started    The page loads with no errors in the browser console (F12 → Console).    The heading, welcome message and all three sections are visible.    The browser tab shows the title "Virtual Dog Park".  The Park    Each "Take to the park" button updates the message under "The Park".    Only one breed card is highlighted at a time.    "Clear the park" removes the highlight and restores the greeting.  Adopting a dog    Pressing Adopt with an empty name shows a message and does not adopt.    Typing only spaces also shows the message.    A name of 20 characters is accepted.    Leading and trailing spaces are removed, but spaces inside the name are kept.    After adopting, the form is replaced by the dog's details and picture.  Looking after the dog    A newly adopted dog starts on Day 1, stage Puppy, happiness 50.    Feed adds 10 happiness.    Play adds 10 happiness.    Pressing Feed or Play at 100 happiness leaves it at 100.    Next Day increases the day by 1 and removes 5 happiness.    Happiness never goes below 0, however many days pass.    The stage reads Puppy on Day 1, Young Dog on Days 2–3, and Adult Dog from Day 4.    The growth bar grows and stops at full.    The stage is written out in words, not shown by the bar alone.  Saving and refreshing    Straight after adopting, refreshing the page brings the same dog back.    After Feed, Play or Next Day, refreshing keeps the new values.    Start Over asks for confirmation first.    Choosing Cancel keeps the dog and its saved progress.    Choosing OK deletes the dog and brings the adoption form back.    Refreshing after Start Over still shows the empty form.  Small screens    Narrow the window, or use the phone view in developer tools.    The layout fits without sideways scrolling.    Headings and body text stay comfortable to read.  About the illustrations  The three dog pictures in assets/ are project-created illustrations. They were
drawn by hand as SVG shapes — circles, ellipses and paths — and each one carries
descriptive alt text such as "Illustration of a Beagle."  They are not photographs, and not photographs of real dogs. The project does not
use any stock photos, image libraries or external image websites.
